# Getting started

This path is for a developer who has never used an agent harness. It should answer three questions before introducing advanced configuration:

1. What problem does Harny solve?
2. How is it different from invoking Claude or Codex directly?
3. What remains under the developer's control?

## Learning path

1. [What is Harny?](what-is-harny.md) — harnesses, workflows, agents, and privileged effects in plain language.
2. [Install Harny](installation.md) — Bun, Git, provider authentication, and a clean verification command.
3. [Run your first workflow](../tutorials/01-command-workflow.md) — a deterministic command-only run with no provider cost.
4. [Run your first feature workflow](first-feature-run.md) — planner, developer, validator, and a validated commit.
5. [Inspect the result](inspect-a-run.md) — branch, worktree, `harny show`, viewer, usage, and cleanup.

Every page in this path should state its prerequisites, expected time, possible provider cost, observable result, and cleanup command.
